The path (and query string) of the Lovelace view to capture. Tip: add the ?kiosk param with the kiosk-mode card to hide the header and sidebar.
Create one in Home Assistant under your Profile → Security → Long-lived access tokens. It is injected into the browser's localStorage so the dashboard loads authenticated.
Extra wait after the page loads so cards finish rendering before the screenshot. On slow hardware (e.g. a Pi Zero 2 W) custom cards with live data need longer — try 12000. Too long risks Home Assistant dropping its connection mid-render.
Size the browser renders at before being scaled down to the display. Leave blank to render at the display resolution. Set this larger than your display (keeping the same aspect ratio) if the dashboard looks zoomed in or content is cut off — e.g. 1000×600 for an 800×480 panel.
Note: rendering a full browser is memory-intensive on a Pi Zero 2 W. If captures fail or the device crashes, simplify the dashboard view.
